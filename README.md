# Personal Portfolio Website

This is my personal portfolio website created using **HTML and basic CSS**. It is a simple website designed to introduce myself and provide my contact information.

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📄 Pages

* **Home** – Introduces me and provides basic information about my profile and skills.
* **Contact** – Provides my contact details for getting in touch with me.

## 🎯 Purpose

I created this project to practice my **HTML and CSS skills** and to build my first personal portfolio website.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## 📁 Project Structure

```text
portfolio/
│
├── index.html
├── contact.html
└── style.css
```

This project demonstrates my basic understanding of **HTML structure, CSS styling, page navigation, and website layout**.
